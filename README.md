Uma linha tem 5 estações.
Cada estação:
Recebe peças
Processa no máximo X por ciclo
Pode quebrar se operar acima de 90% da capacidade por 5 ciclos seguidos
Regras:
Peças não processadas acumulam
Se uma estação quebra:
Toda a linha para
Produção continua até:
Meta diária atingida
Ou falha estrutural
Exibir:
Produção total
Estação que falhou (se houver)
Ciclos executados

2- Controle de Temperatura de Forno
Um forno industrial inicia com temperatura informada pelo usuário.
A cada ciclo:
Se temperatura < 800 → aumenta 50 graus
Se temperatura ≥ 800 e < 1000 → aumenta 20 graus
Se temperatura ≥ 1000 → mantém constante
O sistema deve repetir até:
Atingir 1000 graus
Exibir:
Quantos ciclos foram necessários
Temperatura final

3- Máquina com Desgaste Acumulativo
Uma máquina começa com desgaste 0.
A cada ciclo:
Desgaste aumenta 7 unidades
Se operar acima de 70 ciclos, desgaste aumenta 10 por ciclo
Se desgaste ≥ 500 → máquina quebra
Simular até quebrar.
Exibir:
Quantos ciclos durou
Desgaste final
